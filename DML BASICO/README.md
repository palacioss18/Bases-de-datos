# DML Básico (Data Manipulation Language)

Prácticas sobre las operaciones fundamentales para la manipulación de datos en SQL Server.

## 📌 Conceptos clave
- Filtrado de registros (`WHERE`, `LIKE`, `IN`, `BETWEEN`, `IS NULL`)
- Ordenamiento y paginación (`ORDER BY`, `OFFSET FETCH`)
- Agregación básica (`COUNT`, `SUM`, `AVG`, `GROUP BY`, `HAVING`)

## 📂 Contenido del directorio
- `Filtros.sql`: Consultas condicionales y búsqueda de patrones.
- `Agregacion.sql`: Métricas básicas sobre tablas individuales.
