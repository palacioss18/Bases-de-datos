# Subconsultas y Consultas Correlacionadas

Uso de subconsultas anidadas y correlacionadas para resolver requerimientos de datos complejos.

## 📌 Conceptos clave
- Subconsultas escalares y de lista (`IN`, `EXISTS`, `NOT EXISTS`)
- Subconsultas en cláusulas `FROM` (Derived Tables) y `SELECT`
- Consultas correlacionadas (dependencia entre consulta interna y externa)

## 📂 Contenido del directorio
- `Correlacionadas.sql`: Ejercicios con subconsultas dependientes del contexto.
- `Subconsultas_Basicas.sql`: Filtrado basado en el resultado de otra consulta.
