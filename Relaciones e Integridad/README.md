# Relaciones e Integridad Referencial

Definición de reglas del negocio en la base de datos para garantizar la consistencia de la información.

## 📌 Conceptos clave
- Llaves primarias y foráneas (`PRIMARY KEY`, `FOREIGN KEY`)
- Restricciones de columna (`NOT NULL`, `UNIQUE`, `CHECK`, `DEFAULT`)
- Acciones en cascada (`ON DELETE CASCADE`, `ON UPDATE CASCADE`)

## 📂 Contenido del directorio
- `Constraints.sql`: Implementación de reglas e integridad de datos.
- `Modelo_Relacional.sql`: Creación e interconexión de entidades.
