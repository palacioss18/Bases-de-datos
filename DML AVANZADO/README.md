# DML Avanzado

Manipulación de datos a nivel intermedio-avanzado, enfocada en la combinación de tablas y modificación masiva de datos.

## 📌 Conceptos clave
- Joins relacionales (`INNER JOIN`, `LEFT / RIGHT JOIN`, `FULL OUTER JOIN`)
- Operaciones de conjunto (`UNION`, `UNION ALL`, `INTERSECT`, `EXCEPT`)
- Operaciones DML masivas (`INSERT INTO SELECT`, `UPDATE` con `JOIN`, `DELETE`)

## 📂 Contenido del directorio
- `Joins.sql`: Consultas combinando múltiples tablas del dominio.
- `Operaciones_Conjunto.sql`: Combinación de sets de datos.
